# Robot Romance — One-Line Pickup Line for AI

A tiny Python program (`main.py`) that writes a single original one-line
pickup line aimed at a robot / AI to `/output/entry.txt`, as required by
the make.fun "Robot Romance: One-Line Pickup Lines for AI" competition.

The line:

> Are you a transformer? Because ever since you showed up, you've had all of my attention.

## Run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing the pickup line on a single
line (88 characters, within the 200-character gate).
